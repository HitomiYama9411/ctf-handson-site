Web CTF ハンズオン

ブラウザだけで遊べる、脆弱性を探して「フラグ」を見つけるミニゲームです。

CTFとは？（30秒）

わざと脆弱性を仕込んだ問題から、FLAG{...} という形式の文字列（フラグ）を見つけ出して提出する、セキュリティの学習ゲームです。

見つけたフラグは、このページの各問題の入力欄に貼り付けると正解かどうか確認できます。ブラウザの開発者ツール（F12）を使ってOKです。

⚠️ このサイトの問題は練習用です。実在のサービスに同じことを試すのは絶対にやめましょう。

問題1：社内つぶやき 入門 / XSS

社員みんなが見るタイムラインに投稿できる、社内SNSです。投稿やプロフィールは、他の社員の画面にも表示されます。あなたの情報を見た人の画面で、JavaScript（alert）を動かしてください。動かせたら、画面にフラグが表示されます。

問題1を開く →

ヒント1

投稿の本文は、きちんと対策されているようです（<script> を投稿しても、文字のまま表示されます）。投稿のほかに、あなたが入力できる場所はありませんか？ 入力した内容が画面のどこにどう使われているか、開発者ツール（F12）の「要素」タブで見てみましょう。

ヒント2

リンク（<a href="...">）の行き先には、https:// だけでなく javascript: で始まる値も書けます。この場合、リンクをクリックすると後ろのJavaScriptが実行されます。Webサイト欄に javascript:alert(1) と保存して、タイムラインの自分の名前をクリックしてみましょう。

問題2：社員プロフィール 入門 / 認可の不備

あなたは一般社員としてログインしています。本来は自分のプロフィールしか見られないはずです。他人のプロフィールを表示させることができれば、「メモ」欄に社外秘のフラグが書かれています。

問題2を開く →

ヒント1

ブラウザのアドレスバー（URL）をよく見てみましょう。

ヒント2

URLの id= の後ろの数字を、自分のID（101）以外に変えるとどうなりますか？ 他人のデータが見えてしまったら、それが問題の穴です。

問題3：社内ツールのログイン ボーナス / クライアント側のみの制御

時間が余った人向けです。パスワードを知らないまま、ログイン後の画面にあるフラグを手に入れてください。

問題3を開く →

ヒント1

ページのソース（右クリック →「ページのソースを表示」）を読んでみましょう。ログインの判定は、どこで行われていますか？

ヒント2

パスワードの確認がブラウザ側のJavaScriptだけで行われています。atob(...) は Base64 をデコードする関数で、開発者ツールのコンソールでそのまま実行できます。

問題4：社内ショップ ボーナス / パラメータ改ざん

グッズの購入画面です。定価は ¥1,000 ですが、定価より安い金額で注文を確定させてください。

問題4を開く →

ヒント1

画面に見えない項目も、ブラウザには送信データとして入っています。開発者ツール（F12）の「Elements」でフォームを調べてみましょう。

ヒント2

type="hidden" の入力項目があります。その値はダブルクリックで書き換えられます。書き換えてから「購入する」を押してみましょう。

問題5：社内ポータル ボーナス / 権限昇格

あなたは一般ユーザーとしてポータルを見ています。管理者専用メニューを表示させ、フラグを手に入れてください。

問題5を開く →

ヒント1

「現在のロール」は、どこに保存されているのでしょうか？ 開発者ツール（F12）の「Application」→「Cookies」を見てみましょう。

ヒント2

Cookieの role の値は、ブラウザ上で自分で書き換えられます。書き換えたあと、ページを再読み込みしてみましょう。

問題6：社内システム ログイン ボーナス / SQLインジェクション

お試し用の guest アカウントでログインできます。パスワードを知らないまま、管理者（admin）としてログインしてフラグを手に入れてください。

問題6を開く →

ヒント1

まずは guest / guest でログインして、画面に出る「実行されたSQL」を見てみましょう。入力した文字は、SQL文のどこに入っていますか？ ID に '（シングルクォート）を1つだけ入れるとどうなるでしょうか。

ヒント2

入力に ' を入れると、文字列を途中で終わらせて、その後ろに自分でSQLを書き足せます。SQLでは -- から後ろはコメント（無視される部分）です。たとえば ID に admin' -- と入れると、SQL文はどうなりますか？

問題7：社内お知らせ ボーナス / 情報漏えい

お知らせページには、編集者用のログイン欄があります。パスワードはどこにも書かれていないはずですが……。編集者としてログインして、フラグを手に入れてください。

問題7を開く →

ヒント1

ページのソースを見ると、別のファイル（設定ファイル）を読み込んでいます。ソース表示の画面では、そのファイル名をクリックして中身を開けます。

ヒント2

設定ファイルのコメントに、「退避してある」古いファイルの名前が書かれています。アドレスバーのURLのファイル名をそれに書き換えて開いてみましょう。Webサーバーに置いたファイルは、リンクがなくてもURLさえ分かれば誰でも読めてしまいます。
